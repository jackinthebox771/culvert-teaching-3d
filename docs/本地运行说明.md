# 本地运行说明

## 最简单的方法（Windows）

1. 打开项目文件夹。
2. 双击项目根目录中的 `启动本地项目.cmd`。
3. 等待命令窗口显示 Vite 的启动信息，浏览器会自动打开网页。
4. 使用完成后，回到命令窗口按 `Ctrl+C` 停止服务。

脚本会先自动进入项目目录，因此不会出现从 `C:\Users\用户名` 运行而找不到 `package.json` 的问题。依赖已经存在时，脚本直接调用项目内的 Vite；首次运行且缺少依赖时，脚本会自动执行 `npm install`。

本机默认地址：

```text
http://localhost:5173/culvert-teaching-3d/
```

## 环境要求

- Windows 10 或 Windows 11。
- Node.js `^20.19.0` 或 `>=22.12.0`，建议安装 Node.js 22 LTS。
- 首次安装依赖时需要联网。
- 推荐使用最新版 Chrome、Edge 或 Firefox，并启用 WebGL。

可在命令提示符中检查环境：

```bat
node --version
npm --version
```

## 使用命令手动启动

先进入项目目录，再运行命令。项目路径包含中文和空格时，必须使用英文双引号包裹路径：

```bat
cd /d "D:\绿联云同步\2026_Teaching_画法几何\culvert-teaching-3d"
npm install
npm run dev -- --host 0.0.0.0
```

终端显示 `Local` 和 `Network` 地址后：

- 当前电脑使用 `Local` 地址。
- 同一局域网内的手机或其他电脑使用 `Network` 地址。

不要在 `C:\Users\用户名` 等其他目录直接执行 `npm run dev`，否则 npm 会在错误目录寻找 `package.json`。

## 手机访问

1. 电脑和手机连接同一个 Wi-Fi。
2. 双击 `启动本地项目.cmd`，或使用带 `--host 0.0.0.0` 的手动命令启动。
3. 找到终端输出中的 `Network` 地址，例如：

   ```text
   http://192.168.1.20:5173/culvert-teaching-3d/
   ```

4. 在手机浏览器中输入该完整地址。

如果手机无法打开：

- 确认电脑和手机位于同一局域网，且没有开启网络隔离或 VPN。
- Windows 防火墙弹出提示时，允许 Node.js 访问“专用网络”。
- 使用 `ipconfig` 检查电脑当前 IPv4 地址。
- 确认启动命令包含 `--host 0.0.0.0`。

## 常用检查命令

以下命令都需要在项目根目录运行：

```bat
npm run typecheck
npm run lint
npm run build
```

- `typecheck`：检查 TypeScript 类型。
- `lint`：检查代码规范。
- `build`：生成生产版本到 `dist` 目录。

## 常见问题

### `ENOENT: no such file or directory, open ...\package.json`

原因是命令运行目录不正确。请直接双击 `启动本地项目.cmd`，或先使用 `cd /d` 进入项目根目录。

### `node` 或 `npm` 不是内部或外部命令

安装或重新安装 Node.js 22 LTS，并在安装过程中保持“Add to PATH”选项启用。安装完成后关闭并重新打开终端。

### npm 报告找不到 `npm-cli.js`

通常是 Node.js/npm 安装不完整。项目依赖已经存在时，启动脚本仍可直接调用本地 Vite；若需要重新安装依赖，请从 Node.js 官网重新安装 Node.js 22 LTS。

### 端口 5173 已被占用

Vite 会自动尝试其他端口。请以终端实际显示的 `Local` 和 `Network` 地址为准。

### 页面能够打开但三维模型不可见

- 更新显卡驱动和浏览器。
- 检查浏览器是否启用了硬件加速和 WebGL。
- 打开浏览器开发者工具，查看 Console 是否有资源加载或 WebGL 错误。
