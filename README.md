# 涵洞三维结构教学网页

面向大学《工程制图》课程的涵洞教学工具。本仓库当前完成 **Phase 6C：移动端适配**。实体几何已经用 `docs/涵洞图纸.pdf` 与 `docs/涵洞三维模型.fbx` 交叉核对；课堂功能直接复用正式构件和正交投影，不使用替代示意模型。

## 运行

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

## 坐标系

- Three.js 右手坐标系。
- `Y`：竖直方向，向上为正。
- `Z`：涵洞纵轴/水流方向；前端为 `-Z`，后端为 `+Z`。
- `X`：洞口横向；面向前洞口时左为 `-X`，右为 `+X`。
- 原点：洞身纵横中心线与底板顶面的交点。
- 参数文件以 `mm` 存储；几何工厂通过 `toScene()` 统一换算为场景米。

## 构件层级与稳定 ID

```text
culvert
├── bottom-slab
├── barrel
├── front-headwall
├── rear-headwall
├── front-left-wing-wall
├── front-right-wing-wall
├── rear-left-wing-wall
└── rear-right-wing-wall
```

每个 Three.js 对象的 `name` 和 `userData.componentId` 使用相同稳定 ID。

## 尺寸参数表

唯一尺寸源为 `src/config/culvertDimensions.ts`。正式图纸提供尺寸链，FBX 提供复杂多折面实体与特征坐标；FBX 原始单位经验证为英尺，统一按 `1 ft = 304.8 mm` 换算。当前参数均已由图纸、FBX 或二者交叉确认。

| 构件 | 参数 | 当前值 | 状态 | 依据 |
|---|---|---:|---|---|
| 整体 | 长×宽×总高 | 32000×18000×11500 mm | CONFIRMED | 图纸 + FBX |
| 底板 | 长×洞口宽×厚 | 32000×18000×2500 mm | CONFIRMED | 图纸 + FBX |
| 底板 | 中央段宽 | 12000 mm | CONFIRMED | 图纸 + FBX |
| 底板 | 纵向尺寸链 | 1000+5000+4500+11000+4500+5000+1000 mm | CONFIRMED | 平面图 + FBX |
| 燕尾槽 | 端宽/中宽/深 | 7000/3000/1500 mm | CONFIRMED | FBX 底板网格 |
| 燕尾槽 | 纵向长度 | 30000 mm | CONFIRMED | FBX：1000-31000 |

## Sprint 1 已实现

- 使用 FBX 中八个经图纸核验的独立实体网格，保持稳定构件 ID；不导入整体合并模型。
- 底板包含真实 2500 厚实体、分段台阶外轮廓及 1500 深燕尾形底槽。
- 洞身保留斜边墙、同心内外拱圈和贯通拱形通道。
- 前后面墙保留变截面、拱形穿孔、顶帽和 500×500 倒角。
- 四片翼墙保留 FBX 的多折面变高形体及八字展开关系。
- 教学配色、边缘线、基础灯光、网格与接触阴影。
- OrbitControls 与默认轴测、正面投影图方向、水平投影图方向、侧面投影图方向四个相机预设。
- Debug：XYZ 坐标轴、网格、构件原点、Bounding Box、构件名称、单件显隐、当前原点/尺寸/相机参数。

## Sprint 2 已实现

- 模型表面精确拾取，悬停与选中使用发光材质和增强边缘线提示，不改变构件教学主色。
- 3D 模型、构件树、稳定 ID 和教学信息卡保持双向状态联动。
- 点击场景空白或按 `Esc` 取消选择；隐藏构件不参与拾取。
- 聚焦构件模式将其他构件变为半透明，保留构件间空间关系作为教学参照。
- 各构件提供平滑相机聚焦，并可随时返回四个整体观察方向。
- 教学卡片展示位置、形体特征、制图观察提示与统一参数表中的关键尺寸。

## Sprint 3 已实现

- 统一 `0—100%` 爆炸进度，滑杆可停留在任意中间状态。
- 底板沿 Y 轴下移、洞身沿 Y 轴上移；前后面墙沿 Z 轴分离；翼墙沿各自八字方向斜向移出，八个构件在 100% 时完全分开。
- 分解顺序固定为：底板向下 → 翼墙向两侧 → 面墙向前后 → 洞身向上，每一步占 25% 进度。
- 一键分解、一键组合、25% 逐步分解以及自动往返演示/暂停。
- 构件按“底板 → 翼墙 → 面墙 → 洞身”的教学顺序渐进展开，位移使用平滑缓动。
- 标签、拾取、高亮、隔离和构件相机聚焦均与爆炸位置同步。
- 爆炸时相机按进度自动后退，组合时等量返回，保证全部构件留在视野中。
- 所有位移、阶段区间、教学节点和相机后退量集中在 `src/config/explodeConfig.ts`。

## Phase 4 已实现

- 实体、半透明、X-Ray 三档结构显示模式，材质状态不影响构件拾取。
- 横向、纵向两种实时剖切模式，默认半剖分别保留右半部分（+X）和前端方向（-Z）；剖切位置可连续调节，Debug 模式显示低遮挡剖切面。
- 底板可绕涵洞纵轴翻转 180°，自动隐藏其他构件并切换底视相机，突出燕尾形空槽。
- 关键尺寸、选中构件尺寸和全部尺寸三级标注；尺寸线、尺寸界线、箭头和数值标签均由统一配置生成。
- 底板底视专门标注燕尾槽中央宽度、端部宽度和纵向长度。
- 教学卡片补充构件作用、关键形体特征、制图观察提示和已核对尺寸。

## Phase 5 已实现

- 正面投影图、水平投影图、侧面投影图全部使用独立 `OrthographicCamera`，三维轴测图继续使用透视相机；正面投影从 `-X` 侧观察，使前端 `-Z` 在图中位于左侧并保持四窗端部对应一致。
- 四个视窗通过单一 WebGL 画布与 scissor 视口绘制，避免多上下文占用，并共享同一套已核对几何与构件显隐状态。
- 点击或悬停任一视窗中的构件，其他三个视窗同步高亮；顶部同步显示当前构件正式名称。
- 进入三面投影图时强制恢复组合状态并关闭剖切、翻转、尺寸和透明模式，避免非标准状态干扰投影认知。
- 提供 8 秒投影生成演示：依次建立投影方向，生成正面投影图、侧面投影图和水平投影图，支持暂停、继续和重新生成。
- 三面投影图界面采用正式工程制图术语，不使用“正视图、俯视图、左视图、三视图”。

## Phase 6A 已实现

- 首页提供“开始 5 分钟结构导览”，七步脚本依次讲解整体、底板、洞身、面墙、翼墙、三面投影和重新组合。
- 每一步直接驱动已有的相机、构件选择、隔离、底板翻转、横向剖切和四视窗状态，不创建与正式模型脱离的示意动画。
- 导览卡片包含进度、制图观察重点、上一步、下一步、任意步骤跳转和随时退出。
- 翼墙步骤使用专用水平工作位将模型转正并居中放大，同时高亮四片翼墙、弱化其他构件。
- 结束或退出导览后统一恢复完整组合、默认轴测、实体显示和关闭剖切的安全状态。

## Phase 6B 已实现

- “认构件”：随机高亮正式三维构件，学生从四个稳定构件名称中作答。
- “图找物”：显示随机构件的真实正面投影图、水平投影图或侧面投影图轮廓，学生直接在三维模型中点击对应实体。
- “物找图”：高亮一个三维构件，学生从三张真实正交投影中选择题目指定的投影方向。
- “拼装涵洞”：八个构件从既有 100% 分解位置开始，可逐件拖回组合原点；进入统一吸附阈值后自动归位并显示完成状态。
- 前三项各包含三道随机题，并区分“最终答对”与“首次答对”得分；四项挑战可随时切换、重练或安全退出。
- 挑战模式统一复位透明、剖切、尺寸、翻转和爆炸动画状态，退出后恢复默认完整轴测模型。
- 课堂挑战配置集中在 `src/config/classroomChallengeConfig.ts`，投影预览继续加载同一份经核验 FBX 独立网格。

## Phase 6C 已实现

- 小于 `768 px` 的窄屏优先显示全屏三维模型，桌面构件树、Debug 面板和多层底部控制条改为移动端抽屉。
- 移动端底部常驻精简爆炸滑杆，并提供组合/分解快捷按钮；构件、显示、视角入口使用不小于 40 px 的触控目标。
- 构件抽屉联动构件树和教学信息卡；显示抽屉保留透明、剖切、底板底视、尺寸及完整 Debug 功能；视角抽屉保留四个正式观察方向。
- 导览卡片在手机上限制高度并允许滚动；课堂挑战使用“上方模型 + 下方答题面板”布局，保持三维对象可见。
- 三面投影图在手机上继续使用 2×2 四视窗和独立正交相机，压缩辅助文字但不改变投影方向和构件对应关系。
- 移动端主场景 DPR 降至最高 `1.25`、投影视窗 DPR 降至最高 `1.2`，关闭主方向光实时阴影并将备用阴影图降至 512，桌面质量保持不变。

## 架构

- `src/config/`：尺寸、颜色、相机、构件教学信息、聚焦视角与后续爆炸配置。
- `src/geometry/`：尺寸驱动的后备几何工厂，以及经过单位和坐标归一化的 FBX 独立网格映射。
- `src/components3d/`：将独立几何装配成教学构件。
- `src/scene/`：主视窗 Canvas、灯光、网格、相机控制和爆炸动画驱动。
- `src/projection/`：正交投影相机、四视窗单画布渲染、构件联动与投影生成演示。
- `src/store/`：Zustand 查看器、拾取、隔离、相机和 Debug 状态。
- `src/ui/`：构件树、构件教学卡片、爆炸控制、Debug 面板与相机预设栏。
